# DBZ Fuzion Redux - Calibrated GM Variant

Foundry VTT v13 calibrated system fork for DBZ Fuzion Redux.

Included features:

- Foundry system manifest.
- Character actor type.
- Custom Actor and Item document classes.
- TypeDataModel-style character schema.
- Character sheet with identity, base/effective characteristics, resources, default skills, custom skills, experience, finances, transformations, rolls, attacks, owned items, and biography.
- Live derived calculations.
- Reversible, non-mutating transformation pipeline.
- Skill rolls and attack dialogs/chat cards.
- Item types for techniques, weapons, armor, equipment, qualities, transformations, species, traits, and consumables.
- Item effect rows with configurable targets/modes.
- Embedded quality support on effect-capable item sheets.
- Starter compendium definitions and in-Foundry compendium seeding.
- Ki cost parser helper.
- GM-facing Battle Power calibration diagnostics in `system.powerScaling`.
- Tabbed character sheet (Combat / Character / Items / Progression / Bio / GM) with an always-visible
  resource header, bundled display fonts, and an inline icon sprite.
